Analisador OSG

Política de Privacidade e Termos de Uso

Última atualização: 11 de agosto de 2026

1. Sobre este documento

O Analisador OSG ("a Ferramenta") é um serviço de análise de Orçamento Sensível ao Género (OSG / Gender-Responsive Budgeting), disponibilizado a organizações e instituições através de um código de acesso individual. Este documento explica que dados são recolhidos, como são tratados, e em que condições a Ferramenta pode ser usada.

2. Que dados são recolhidos

2.1 Texto submetido para análise

O texto orçamental que introduz ou carrega (PDF, Excel, CSV ou TXT) é enviado para um serviço intermediário ("o Worker") que o reencaminha para a API da Anthropic (fornecedora do modelo de inteligência artificial Claude) exclusivamente para gerar a análise solicitada. Este texto não é utilizado pela Anthropic para treinar modelos de IA, ao abrigo dos termos comerciais da API da Anthropic.

2.2 Histórico de análises

Quando uma análise é concluída, um resumo (excerto do texto, resultado da análise, marcadores atribuídos e eventuais correções manuais) é guardado associado ao código de acesso da sua organização, num armazenamento gerido pelo administrador do Analisador OSG (Cloudflare Workers KV). Este histórico é visível apenas para quem tiver o código de acesso dessa organização, e para o administrador da Ferramenta.

2.3 Dados de utilização

É registado o número de análises realizadas por código de acesso e por mês, para efeitos de aplicação dos limites do plano contratado. Não são recolhidos dados de localização em tempo real, nem identificadores publicitários.

2.4 Dados de pagamento

Os pagamentos são processados pela Stripe, Inc. O Analisador OSG não armazena números de cartão de crédito nem outros dados financeiros sensíveis; recebe apenas a confirmação do pagamento e o endereço de email associado, para criar o código de acesso correspondente.

3. Como os dados são usados

  • Gerar a análise solicitada e o relatório completo, quando pedido.
  • Manter o histórico de análises da organização, para consulta e comparação ao longo do tempo.
  • Aplicar os limites de utilização do plano contratado.
  • Processar o pagamento e emitir o código de acesso correspondente.

Os dados não são vendidos, alugados nem partilhados com terceiros para fins de marketing. Não são utilizados para treinar modelos de inteligência artificial, próprios ou de terceiros.

4. Onde os dados são processados

A Ferramenta assenta em três serviços de infraestrutura:

  • Cloudflare Workers e Cloudflare Workers KV — alojamento do serviço intermediário e armazenamento do histórico e dos códigos de acesso.
  • API da Anthropic — geração da análise através do modelo Claude.
  • Stripe — processamento de pagamentos.

Estes fornecedores processam dados em servidores fora da Guiné-Bissau. Organizações com requisitos legais específicos sobre localização de dados devem confirmar com o administrador da Ferramenta se esta configuração é compatível com as suas obrigações antes de submeterem informação orçamental sensível.

5. Recomendações para quem usa a Ferramenta

  • Evite incluir dados pessoais identificáveis desnecessários no texto analisado (nomes de beneficiários individuais, números de identificação, moradas).
  • A Ferramenta foi concebida para analisar orçamentos públicos, documentos já do domínio público ou de uso interno da organização — não para processar dados pessoais sensíveis de terceiros.
  • Cada organização é responsável por garantir que a submissão do seu orçamento à Ferramenta cumpre as suas próprias políticas internas de proteção de dados.

6. Retenção e eliminação de dados

O histórico de análises é mantido enquanto o código de acesso da organização estiver ativo. Cada organização pode eliminar entradas individuais do seu próprio histórico a qualquer momento, diretamente na Ferramenta. Para solicitar a eliminação completa do histórico de uma organização, ou a desativação de um código de acesso, contacte o administrador da Ferramenta.

7. Natureza da análise (limitações)

A análise apresentada pela Ferramenta é gerada por inteligência artificial com base exclusivamente no texto fornecido pelo utilizador. Não substitui a avaliação de um/a especialista em orçamentação sensível ao género, nem constitui aconselhamento jurídico, financeiro ou de auditoria. Deve ser revista e validada por um/a profissional qualificado/a antes de qualquer uso oficial, decisório ou de publicação institucional.

8. Termos de uso

8.1 Acesso

O acesso à Ferramenta é feito através de um código de acesso associado a uma organização, com um limite mensal de análises definido pelo plano contratado. O código de acesso não deve ser partilhado fora da organização à qual foi atribuído.

8.2 Uso aceitável

A Ferramenta destina-se à análise de orçamentos públicos e documentos de planeamento orçamental sob a perspetiva de género. Não deve ser usada para processar dados pessoais sensíveis de terceiros, nem para fins que violem a legislação aplicável no país de origem da organização.

8.3 Disponibilidade

A Ferramenta é fornecida "tal como está". Apesar dos esforços para garantir disponibilidade e fiabilidade, o administrador não garante funcionamento ininterrupto e não se responsabiliza por perdas resultantes de indisponibilidade temporária, falhas de terceiros (Cloudflare, Anthropic, Stripe) ou uso indevido do código de acesso.

8.4 Alterações

Este documento pode ser atualizado periodicamente. Alterações materiais serão comunicadas às organizações com código de acesso ativo.

9. Contacto

Para questões sobre privacidade, tratamento de dados, ou os presentes termos, contacte o administrador do Analisador OSG através dos canais habituais de suporte da sua organização.
